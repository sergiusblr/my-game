
# Not Sudoku: 10 in a Square — GitHub Pages Site

## Quick deploy
1) Create a repository on GitHub (e.g., `not10-site`).
2) Put the contents of this folder in the repo root.
3) In GitHub → Settings → Pages → Source: `Deploy from a branch`, Branch: `main`, Folder: `/ (root)`.
4) Wait 1–2 minutes. Your site will be live at `https://USERNAME.github.io/REPO/`.
5) Update links in:
   - `index.html` (Google Play button URL)
   - `privacy.html` (contact email)
   - `sitemap.xml` (domain)
   - `contact.html` (Formspree action)

## Optional
- Add a `CNAME` file with your custom domain (e.g., `not10game.com`).
