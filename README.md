# "Кого я уже пережил" — MVP

Небольшой веб‑сервис на HTML/CSS/JS, который показывает известных людей, умерших в возрасте не больше указанного. Работает полностью в браузере, без сервера. Готов к деплою на GitHub Pages.

## Возможности
- Ввод даты рождения или возраста (возраст приоритетнее)
- Автоматический подсчёт возраста при вводе даты рождения
- Запрос к Wikidata SPARQL API:
  - Фильтр по людям (P31=Q5) с датами рождения (P569) и смерти (P570)
  - Возраст на момент смерти ≤ ваш возраст
  - Имя, годы жизни, точный возраст, профессии (P106), гражданство (P27), изображение (P18), ссылка на статью
- Доп. запрос к Wikipedia REST API /page/summary:
  - краткое описание, thumbnail, ссылка
  - кэширование в localStorage на 7 дней
- Адаптивная сетка карточек, тёмный минималистичный дизайн
- Языки интерфейса: ru/en
- Пагинация (LIMIT/OFFSET) кнопкой «Показать ещё»
- Счётчик: «Вы пережили X известных людей»
- Скелетон‑заглушки при загрузке
- Шаринг: параметры `?age=` и `?lang=` в URL

## Технологии
- Чистый HTML + CSS + JavaScript
- Все запросы идут напрямую к публичным API (без бэкенда)

## Запуск локально
1. Откройте `index.html` в браузере (двойной клик) — всё работает без сборки.
2. При необходимости поднимите простой http‑server, например:
   - Python: `python3 -m http.server` и откройте `http://localhost:8000`

## Деплой на GitHub Pages
1. Создайте репозиторий и положите файлы в корень: `index.html`, `style.css`, `app.js`, `README.md`.
2. В настройках репозитория включите Pages → Deploy from branch → `main` / root.
3. Через минуту сайт будет доступен на `https://<user>.github.io/<repo>/`.

## Структура
- `index.html` — разметка и UI
- `style.css` — тёмная тема, сетка, карточки, скелетоны
- `app.js` — логика: URL‑параметры, i18n, вычисление возраста, запросы к Wikidata и Wikipedia, пагинация, рендер

## Замечания по данным и лицензиям
- Данные: Wikidata — CC0
- Тексты: Wikipedia — CC BY‑SA 3.0
- Изображения: Wikimedia Commons (условия зависят от файла)

Атрибуция указывается в футере приложения.

## Ограничения и квоты
- Публичные API имеют квоты. При интенсивном использовании возможны задержки и ограничения.
- SPARQL запрос может занимать время; при больших значениях `age` результатов много — используйте «Показать ещё».

## Локализация
- Переключатель `ru/en` в шапке. Выбранный язык отображается в URL `?lang=`; можно делиться ссылкой.

## Конфиденциальность
- Приложение не отправляет ваши данные на собственный сервер. Кэш описаний Wikipedia хранится в `localStorage` 7 дней.
